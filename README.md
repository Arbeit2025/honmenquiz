# honmenquiz

本免（普通自動車免許の本免許学科試験）対策の、○×（まるばつ）カード形式クイズアプリです。単一ファイルの Flask アプリで、問題はすべてこのリポジトリ内で自作した学習用問題です。

## 概要

- 問題数：全120問（自作）
- カテゴリ：法規の基礎／標識・標示／高速道路／安全運転／車両・応急・その他（各24問）
- モード：ランダム10問／全問120問／カテゴリ別（24問）
- 回答するとその場で正解・不正解と解説を表示
- 結果画面でスコアと合格ライン目安（90%）を表示し、間違えた問題を一覧表示
- 間違えた問題はブラウザの localStorage に保存され、「間違えた問題だけ復習」で繰り返し解けます
- ライト／ダークテーマ切り替え対応（設定は localStorage に保存）

## 免責

- 本アプリの問題は学習用の自作問題です。公式の試験問題ではありません。
- 本免学科試験は ○×問題90問とイラスト問題（危険予測）5問で構成されますが、本アプリは ○×問題のみを扱い、**イラスト問題（危険予測）は含みません**。
- 法令の改正などにより内容が現行制度と異なる場合があります。最終的には最新の公式教材で確認してください。

## 使い方

```bash
pip install -r requirements.txt
python3 app.py
# http://localhost:5000 を開く
```

本番相当の起動（Render 等）:

```bash
gunicorn app:app
```

## エンドポイント

- `/` : クイズ画面（問題データはページ内に埋め込み）
- `/api/questions` : 問題データの JSON
- `/healthz` : ヘルスチェック（`{"status": "ok"}`）

## テスト

```bash
python3 -m unittest discover -s tests
```
